# Pipeline Graph Experience Opportunities

- Provide reusable templates and presets for common render techniques (e.g., bloom, deferred shading) so artists can start from familiar blueprints instead of authoring every connection from scratch.
- Offer live performance profiling overlays for nodes and pipelines to highlight cost hotspots directly inside the editor, helping demoscene creators tune complex graphs in real time.
- Allow collaborative comments or annotations on nodes/pipelines to capture artistic intent, shader tricks, or to-do items for teams iterating on effects.
- Integrate asset dependency tracking so editing a shader automatically surfaces which pipelines and textures will be impacted before compilation.
- Expose timeline or keyframe-driven controls that can drive uniform/buffer parameters, enabling quick motion design iterations without leaving the editor.
